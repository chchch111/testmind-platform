# 云服务器部署注意事项

## 一、部署架构说明

本项目可以部署在普通 CPU 云服务器上，不需要 GPU。部署时需要注意：

1. FastAPI 后端服务运行在云服务器 CPU 环境。
2. bge-small-zh Embedding 模型运行在应用服务端内部。
3. FAISS 向量索引文件保存在服务器磁盘目录中。
4. MySQL 可部署在同一台服务器，也可使用云数据库。
5. DeepSeek-v4-flash 通过公网 API 调用，因此服务器必须能访问外网。

推荐云服务器最低配置：

```text
CPU：2核或以上
内存：4GB或以上，建议8GB
磁盘：40GB或以上
系统：Ubuntu 22.04 LTS 或 Windows Server
Python：3.11或3.13均可，当前本机使用Python 3.13测试通过
MySQL：8.0+
```

## 二、目录权限要求

部署时必须保证以下目录具有读写权限：

```text
storage/faiss
storage/uploads
storage/exports
storage/models
```

如果权限不足，可能导致：

1. XMind 文件上传失败。
2. XMind 文件导出失败。
3. FAISS index.faiss 无法写入。
4. docstore.json 无法保存。
5. bge-small-zh 模型无法下载或缓存。

Linux 服务器可执行类似命令：

```bash
mkdir -p storage/faiss storage/uploads storage/exports storage/models
chmod -R 755 storage
```

## 三、环境变量配置

生产环境必须使用 `.env` 配置敏感信息，不能把密钥写死在代码中。

关键配置示例：

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_USER=root
MYSQL_PASSWORD=你的MySQL密码
MYSQL_DATABASE=rag_mindmap_test_platform

FAISS_ROOT_DIR=/opt/rag_mindmap_platform/storage/faiss
UPLOAD_ROOT_DIR=/opt/rag_mindmap_platform/storage/uploads
EXPORT_ROOT_DIR=/opt/rag_mindmap_platform/storage/exports

EMBEDDING_MODEL_NAME=BAAI/bge-small-zh-v1.5
HF_HOME=/opt/rag_mindmap_platform/storage/models/huggingface
RAG_CHUNK_SIZE=500
RAG_CHUNK_OVERLAP=80
RAG_TOP_K=5

DEEPSEEK_BASE_URL=https://api.deepseek.com/v1
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_API_KEY=你的DeepSeek密钥
```

## 四、FAISS 文件持久化要求

FAISS 索引文件必须持久化保存，不能放在临时目录。

系统会生成类似文件：

```text
storage/faiss/kb_3/main/index.faiss
storage/faiss/kb_3/main/docstore.json
```

其中：

1. index.faiss 保存向量索引。
2. docstore.json 保存 FAISS 向量位置与 MySQL chunk_id 的映射关系。
3. MySQL 保存知识切片文本和索引元数据。

如果服务器迁移，需要同时迁移：

```text
MySQL 数据库
storage/faiss 目录
storage/uploads 目录
storage/exports 目录，可选
storage/models 目录，可重新下载
```

## 五、DeepSeek API 网络要求

AI 生成功能依赖 DeepSeek 云端 API。

如果服务器无法访问公网，以下功能会不可用：

```text
POST /api/ai/generate-case-set
```

但以下功能仍可使用：

```text
用例集管理
版本记录与回退
XMind导入导出
测试任务管理
RAG本地向量检索，前提是模型和索引文件已存在
```

## 六、模型缓存注意事项

Embedding 模型使用：

```text
BAAI/bge-small-zh-v1.5
```

模型首次运行时会从 HuggingFace 下载。为了避免缓存到系统盘，必须设置：

```env
HF_HOME=/opt/rag_mindmap_platform/storage/models/huggingface
```

Windows 本地开发时对应路径为：

```env
HF_HOME=D:/csdn_projects/rag_mindmap_platform/storage/models/huggingface
```

## 七、启动命令示例

开发环境启动：

```bash
cd /opt/rag_mindmap_platform/backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python scripts/init_db_safe.py
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Windows 本地启动：

```bash
cd D:/csdn_projects/rag_mindmap_platform/backend
.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

## 八、生产部署建议

正式部署时建议：

1. 使用 Nginx 反向代理 FastAPI。
2. 使用 systemd 或进程管理工具守护 uvicorn/gunicorn。
3. 使用 HTTPS 保护 API 访问。
4. `.env` 文件不要提交到 Git 仓库。
5. DeepSeek API Key 只保存在服务器环境变量或 `.env` 文件中。
6. 定期备份 MySQL 和 storage/faiss。
7. 限制上传文件大小，防止超大 XMind 或文档耗尽磁盘。
8. 对管理接口增加登录认证和权限控制。

## 九、常见部署问题

### 1. FAISS 索引构建失败

可能原因：

```text
storage/faiss 没有写权限
faiss-cpu 没有安装成功
服务器内存不足
```

### 2. bge-small-zh 模型下载失败

可能原因：

```text
服务器无法访问 HuggingFace
HF_HOME 目录没有写权限
网络不稳定
```

解决方式：

```text
可以先在本机下载模型缓存，再复制到服务器 HF_HOME 目录。
```

### 3. AI生成接口失败

可能原因：

```text
DEEPSEEK_API_KEY 未配置
服务器无法访问外网
DeepSeek API 余额或权限异常
模型名称配置错误
```

### 4. XMind 导入失败

可能原因：

```text
上传文件不是新版 .xmind
文件中缺少 content.json
XMind 文件结构不标准
上传目录没有写权限
```

## 十、论文中可写的部署结论

本系统的 Embedding 和 FAISS 检索模块可部署在普通 CPU 云服务器上，不需要 GPU 资源，适合中小规模知识库场景。系统仅在大模型推理阶段调用 DeepSeek-v4-flash 云端 API，因此在保证公网可访问的条件下，可以实现测试用例自动生成能力。FAISS 索引文件和 MySQL 数据库需要同时持久化保存，以保证服务重启或服务器迁移后知识库不丢失。
